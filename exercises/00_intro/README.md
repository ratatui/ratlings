# Welcome

Before the trip, a look around the kitchen.

Ratlings teaches Ratatui one small exercise at a time. Each lesson is a plain
Rust file you edit in your own editor, and a viewer that shows your app at the
real size of your terminal with the lesson floating on top.

## What you'll learn

- What the canvas is, and that ratlings never touches it.
- The handful of keys that drive every lesson: `esc`, `C-g`, `h`, `?`, `n`.
- The loop the whole course runs on: read, edit, check, move on.
